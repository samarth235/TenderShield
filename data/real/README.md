# Real datasets

- `cpv_2008_codes.csv` - Common Procurement Vocabulary (CPV 2008), 9,454 codes, from Commission
  Regulation (EC) No 213/2008. Copy obtained from github.com/KhawarMehfooz/tender-management-system.
- `raw/` (not committed) - downloaded by `backend/scripts/fetch_real_data.py`; every file is listed in
  `raw/MANIFEST.json` with URL, size and SHA-256.

See `docs/real-data.md` for licences and how each dataset is used.
